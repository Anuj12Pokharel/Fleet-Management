# Fleet-Management System

Full-stack FleetCare Management Application for commercial trucking fleets, featuring eDVIR checklists, dual-trigger Preventive Maintenance (PM) calculations, driver GPS telemetry tracking, roadside DOT audit trails, expense/TCO analytics, and real-time NestJS backend database integration.

## Features
- **Dashboard & Analytics**: Real-time asset health monitoring, compliance tracking, and CSV reports generation.
- **Asset Telematics & Fleet Map**: Interactive Leaflet asset locations, dynamic GPS mapping, and Supertruck AI driver tracking integration.
- **Inspections & Compliance**: Electronic Driver Vehicle Inspection Reports (eDVIR) and federal DOT roadside inspection audit logs.
- **Preventive Maintenance & Work Orders**: Dual-trigger (mileage & days) PM schedules, service requests triage, mechanic assignment, and parts inventory tracking.
- **Financial Matrix & TCO**: Fuel log anomaly detection, IFTA filing reports, toll transponder matching, and replacement lifecycle intelligence.

## Tech Stack
- **Frontend**: Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide Icons, Leaflet Maps
- **Backend**: NestJS, TypeScript, Prisma ORM, SQLite Database
